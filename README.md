# 👕 MISTO — Fashion Clothing Store Website

**MISTO** is a modern and stylish clothing store website designed to showcase fashion products with a clean and user-friendly interface.  
The project focuses on simplicity, performance, and a smooth user experience across all devices.

---

## ✨ Features

- 🛍️ Men’s and Women’s clothing sections
- 🔍 Product browsing and filtering
- 📱 Fully responsive design (mobile, tablet, desktop)
- ⚡ Fast development and build with Vite
- 🎨 Clean and modern UI design
- 🔗 Seamless page navigation using React Router

---

## 🛠️ Built With

- **React.js**
- **Vite**
- **React Router DOM**
- **CSS / Styled Components**
- **JavaScript (ES6+)**
